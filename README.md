# 简历工坊

成熟专业的中文简历制作工具，面向职场求职与博士学术 CV。

- 10 大模板类别、100 套不同版式
- 10 种正文结构 × 10 种页眉结构，结构组合不重复
- 博士论文、科研项目、研究方向、专利与奖项模块
- 实时预览、主题色与排版密度调节
- 浏览器自动保存、JSON 备份与恢复
- A4 PDF 打印导出

在线地址：https://mrdou01.github.io/resume-studio/

模板体系参考了 [Reactive Resume](https://github.com/AmruthPillai/Reactive-Resume)、[RenderCV](https://github.com/rendercv/rendercv)、[Awesome-CV](https://github.com/posquit0/Awesome-CV) 与 [JSON Resume](https://github.com/jsonresume/resume-schema) 的公开设计思路，并针对中文内容重新设计。
